# 新蓝 TV 界面设计

版本：0.3.0。日期：2026-10-23。开发分支：`feat/tv-interface`。

## 本版方向

采用原生 Android View 绘制电视菜单，围绕远距离阅读和遥控器操作组织信息。没有增加 UI 运行时依赖，也不依赖图片下载、背景模糊或复杂动画。

- 整体为深蓝渐变底色，打开菜单时覆盖视频，保证文字对比度。
- 顶部显示品牌图标、当前观看频道、北京时间与星期。
- 左侧为独立频道侧栏，编号、频道名称、当前节目摘要分别排版。
- 右侧显示频道名称和全天节目单；每个节目将起止时间、完整名称和播出状态分栏显示。
- 底部集中显示遥控器提示，随频道、节目与刷新按钮的焦点变化。

## 视觉语义

| 元素 | 处理方式 |
| --- | --- |
| 普通卡片 | 深蓝底、细描边、浅色主文字与灰蓝色辅助文字 |
| 遥控器焦点 | 蓝色渐变、高亮描边与轻微阴影 |
| 正在观看的频道 | “正在看”标记；移开焦点后保留青绿色底色 |
| 正在播出的节目 | 青绿色时间与标签，显示实时播出进度 |
| 已播节目 | 较弱的文字颜色，保留完整名称与时间 |
| 待播节目 | 明亮名称与辅助状态标签 |
| 刷新按钮 | 独立图标按钮，使用相同的蓝色焦点样式 |

频道摘要最多显示两行，完整节目名称在右侧列表中自然换行。时间与频道编号使用统一的数字排版；列表初始位置对齐频道卡片的顶部，避免从一张卡片的标题中部开始显示。

## 继续保留的交互

- 频道区左键到达边界后保持当前位置；刷新按钮上继续右键也保持当前位置。
- 频道区右键进入节目，节目区右键直达刷新按钮。
- 节目区上下键支持长按浏览，从刷新按钮按下可从当天第一个节目开始浏览。
- 当前频道确认操作只关闭菜单并继续直播；其他频道才加载切台。
- 返回键从节目区回频道区，再关闭菜单。菜单键直接切换菜单可见性。
- 刷新同频道数据时保留正在浏览的节目焦点；当前节目与焦点使用不同颜色。

## 验证环境与产物

- 使用用户在 Android Studio 中安装的 Android TV API 36 arm64 镜像及 `Television_4K` AVD。
- 原生画面尺寸为 3840 × 2160，密度 640，对应 960 × 540 dp。
- 通过 adb 安装当前 APK，实际启动应用、读取节目单并播放直播。
- 通过遥控器按键驱动 UI，使用 uiautomator 界面树确认焦点、菜单和频道状态，保存真实截图。
- 15 项模拟器流程检查通过，覆盖边界导航、节目与刷新焦点、手动刷新、从午夜开始浏览、长按、同频道确认、不同频道切台和返回层级。另对长节目名称做了稳定画面的视觉核对；本次崩溃日志为空。
- 30 项节目单单元测试通过，APK 构建和签名验证通过，Android Lint 为 0 个错误、7 个既有配置 / 工具版本警告。
- 本地证据保存在 `app/build/qa/`：美化前后截图、频道 / 节目 / 刷新焦点状态、其他频道预览、播放画面和按键检查记录。
- 截图与临时检查输出属于构建产物，不纳入 Git；设计代码和文档纳入版本控制。

本次是第一轮视觉实现，可根据实际电视上的观看距离、字体偏好、信息密度和配色反馈继续调整。模拟器验证不能代替物理电视的 WebView 与解码兼容性验证。
